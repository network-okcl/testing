# OKCL Centre Registration Portal

Website for registering new centres with OKCL and checking registration status.
Built with Next.js; data will live in Google Sheets via Google Apps Script.

## Run it on your computer
1. Install [Node.js](https://nodejs.org) (version 20 or newer).
2. In this folder run `npm install`, then `npm run dev`.
3. Open http://localhost:3000
